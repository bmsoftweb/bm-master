# BM-Master (Gerenciador Web)

Cadastro central dos sistemas BMsoft: grupos, empresas, usuários, perfis e lançador de módulos.
Vite + React + Express, deploy na Vercel.

1. `npm install`
2. Copiar `.env.example` para `.env` e preencher MySQL e `SESSION_SECRET`.
3. `npm run dev` (porta do `PORT`, padrão 3000).

`npm run lint` (tsc) e `npm run build` (Vite + esbuild do servidor).
